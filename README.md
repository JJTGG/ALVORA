# ALVORA

**Self-hosted infrastructure for full-stack developers.**

ALVORA is an independent developer-cloud project designed to deploy and operate complete applications—including runtimes, PostgreSQL databases, object storage, authentication, jobs, domains and observability—without requiring third-party managed services for core operation.

## Status

ALVORA is in the documentation and architecture-preparation phase. It is not yet implemented or production-ready. Proposed capabilities are not completed features.

## Direction

ALVORA is designed to bootstrap on operator-controlled infrastructure, manage applications and backend resources through a resource-oriented control plane, build and deploy its own platform services, provide self-hosted infrastructure primitives, support offline recovery, and progress from a single node to multi-node and multi-region operation.

## Independence

ALVORA is separate from NEXVARIN. It has its own repository, architecture, lifecycle, APIs, data model and deployment model. NEXVARIN is not a runtime dependency or shared implementation foundation.
